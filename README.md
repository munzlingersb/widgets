# widgets

Widgets HTML estáticos para embed em Notion, Trello, etc.

Hospedado via GitHub Pages.

## Widgets

- [`notion-progress-tracker.html`](notion-progress-tracker.html) — barra de progresso horizontal de 5 etapas. Pra atualizar, edite a constante `STEP` (1 a 5) no final do arquivo.

## Embed no Notion

`/embed` → cola URL do Pages → ajusta altura.
